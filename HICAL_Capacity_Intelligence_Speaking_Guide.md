## Objection Handling & Executive Q&A

| Potential Executive Objection | Strategic Response / Talking Point |
| :--- | :--- |
| *"Will this project slow down our live SAP system?"* | **Zero Impact:** All extracts are read-only, indexed, and executed every 4 hours during scheduled intervals, requiring negligible compute overhead. |
| *"What if our SAP master data or routing times are not 100% clean?"* | **Pre-flight Audit:** Weeks 1–2 of Phase 1 include automated data quality checks against your current spreadsheets to isolate gaps before deployment. |
| *"Can we deploy this directly in our existing Tableau environment?"* | **Native Integration:** Yes, the entire cockpit is engineered natively for Tableau Server / Cloud, eliminating new software license friction. |
| *"Why not jump straight to SAP ePPDS?"* | **Prerequisite Foundation:** Advanced ePPDS finite scheduling requires reliable backlog status and validated capacity constraints. Phase 1 provides that foundation rapidly and affordably. |
